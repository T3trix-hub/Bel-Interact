# Bel-Interact
🇷🇺 Русский

Интерактивная карта Беларуси на чистом SVG и Vanilla JS без библиотек. 200+ объектов: города, агроусадьбы, отели, замки, музеи и природа. Зум, панорамирование, мультитач для мобильных, умная фильтрация объектов по масштабу. Тёмная и светлая темы, 3 языка (русский, английский, китайский). У каждого места — описание, фото, интересный факт, GPS-координаты и кнопка построения маршрута в Яндекс.Картах. Проект для портфолио.

🇬🇧 English

Interactive map of Belarus built with pure SVG and Vanilla JS — no third-party libraries. 200+ locations including cities, agro-estates, hotels, castles, museums and natural sites. Features zoom, pan, multitouch for mobile, and smart object filtering by zoom level. Includes dark/light themes and 3 languages (Russian, English, Chinese). Each place comes with description, photos, fun facts, GPS coordinates, and a route builder to Yandex.Maps. Portfolio-ready project.
